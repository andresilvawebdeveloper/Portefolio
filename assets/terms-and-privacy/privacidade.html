Política de Privacidade

A proteção dos seus dados é uma prioridade. Esta política explica como os seus dados são tratados de acordo com o RGPD.

1. Recolha de Dados

Recolhemos dados através do formulário de contacto (Nome, E-mail) e dados de faturação necessários para o processamento de pagamentos via Stripe.

2. Finalidade

Os dados recolhidos servem exclusivamente para a prestação dos serviços contratados, comunicação direta e cumprimento de obrigações fiscais.

3. Segurança de Pagamentos

Não armazenamos dados de cartões de crédito nos nossos servidores. Todos os pagamentos são geridos de forma segura pelo Stripe, que cumpre com os padrões PCI-DSS.

4. Seus Direitos

Pode solicitar a qualquer momento o acesso, retificação ou eliminação dos seus dados pessoais através do e-mail de contacto presente neste site.

5. Contacto do Responsável
